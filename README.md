# Armstrong Edit downloads

Installers for Armstrong Edit, an easy video editor for Windows.

**To install:** open [the latest release](../../releases/latest), download `Armstrong-Edit-Setup-x.y.z.exe` and run it.
Windows may show "Windows protected your PC" because the installer is not signed: choose **More info**, then **Run anyway**.

The app puts a shortcut on the desktop and keeps itself up to date.
